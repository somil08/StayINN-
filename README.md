# 🏡 StayINN

StayINN is a **full-stack rental platform** inspired by Airbnb, allowing users to **list, search, and book rental properties** 
with geolocation support and secure authentication.

The project emphasizes **production-grade deployment**, scalability, and cloud-native infrastructure.

---

## 🚀 Features

- 🔐 Secure Authentication with Passport.js
- 🏘️ Property Listing & Booking System
- 🗺️ Location-based Search using Mapbox
- 📸 Image Uploads via Cloudinary
- 🧑‍💻 Server-side Rendering using EJS
- 🐳 Dockerized Microservices
- ☁️ Deployed on AWS ECS Fargate
- ⚖️ Load-balanced with ALB
- 📈 Auto-scaling & Health Checks (99% uptime)
